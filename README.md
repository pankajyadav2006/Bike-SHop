# BikeVerse

A modern, responsive e-commerce platform for premium bikes and accessories. Created by Pankaj Yadav.

## Features

- **Modern Shopping Interface**: Clean and intuitive design for seamless shopping experience
- **Shopping Cart**: Add items to cart, adjust quantities, and manage your selections
- **Responsive Design**: Fully responsive on all devices from mobile to desktop
- **Product Filtering**: Filter products by category, brand, and price range
- **Product Search**: Easily find products with the search functionality

## Tech Stack

- React
- JavaScript
- Material-UI
- Redux Toolkit
- React Router
- Framer Motion (for animations)

## Getting Started

### Prerequisites

- Node.js (v14.0 or higher)
- npm

### Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/bike-verse.git
   cd bike-verse
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Start the development server:
   ```
   npm run dev
   ```

4. Open your browser and visit:
   ```
   http://localhost:5173
   ```

## Project Structure

- `public/img/` - Product and website images
- `src/components/` - Reusable React components
- `src/pages/` - Main page components (Home, Shop, Cart)
- `src/store/` - Redux store configuration and slices
- `src/theme.js` - Material-UI theme configuration
- `src/App.jsx` - Main application component
- `src/main.jsx` - Application entry point

## Available Scripts

- `npm run dev` - Starts the development server
- `npm run build` - Builds the app for production
- `npm run lint` - Lints the codebase
